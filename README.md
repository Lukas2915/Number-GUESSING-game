# თამაში „გამოიცანი რიცხვი“

ეს არის Python-ზე შექმნილი მარტივი კონსოლური თამაში. პროგრამა ირჩევს შემთხვევით რიცხვს, ხოლო მოთამაშე ცდილობს მის გამოცნობას.

## თამაში

1. გაუშვით პროგრამა.
2. შეიყვანეთ თქვენი ვარაუდი.
3. მიჰყევით პროგრამის მინიშნებებს და სცადეთ რიცხვის გამოცნობა.

## მოთხოვნები

- Python 3

## გაშვება

ტერმინალში გადადით პროექტის საქაღალდეში და გაუშვით:

```bash
python main.py
```

თუ თქვენს სისტემაში Python 3-ის ბრძანებაა `python3`, გამოიყენეთ:

```bash
python3 main.py
```

## პროექტის ფაილები

- `main.py` — თამაშის ძირითადი კოდი.
