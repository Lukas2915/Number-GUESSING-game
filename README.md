# თამაში „გამოიცანი რიცხვი“

ეს არის Python-ზე შექმნილი კონსოლური თამაში, რომელშიც მოთამაშე ცდილობს პროგრამის მიერ არჩეული შემთხვევითი რიცხვის გამოცნობას.

## შესაძლებლობები

- თამაშის დაწყება.
- რიცხვის გამოცნობისას პროგრამის მინიშნებების მიღება.
- თამაშიდან გამოსვლა.
- მოგებული თამაშების ისტორიის ნახვა.

## როგორ ვითამაშოთ

გაუშვით პროგრამა, აირჩიეთ თამაშის დაწყება და შეიყვანეთ რიცხვი. მიჰყევით პროგრამის მინიშნებებს. მენიუში შეგიძლიათ თამაშიდან გამოსვლა ან მოგებების ისტორიის ნახვა.

## მოთხოვნები

- Python 3

## გაშვება

ტერმინალში გადადით პროექტის საქაღალდეში და გაუშვით:

```bash
python main.py
```

თუ თქვენს სისტემაში Python 3-ის ბრძანებაა `python3`, გამოიყენეთ:

```bash
python3 main.py
```

## პროექტის ფაილები და ფუნქციები

- `main.py` — თამაშის კოდი, რომელიც შეიცავს თამაშის დაწყების, გამოცნობის, გამოსვლისა და მოგებების ისტორიის ნახვის ლოგიკას.

## კოდის ზომა

`main.py`-ის ზუსტი სტრიქონების რაოდენობა და ფუნქციების სახელები აქ მითითებული არ არის, რადგან წყაროს ფაილი სამუშაო საქაღალდეში ხელმისაწვდომი არ აღმოჩნდა. რიცხვისა და ფუნქციების სახელების ზუსტად დასამატებლად საჭიროა `main.py`-ის შიგთავსი.
